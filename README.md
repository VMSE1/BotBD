# BotBD: приватная ведомость курса Python

Робот раз в час забирает сдачи из публичного репозитория курса ([VMSE1/python](https://github.com/VMSE1/python)) и раскладывает по группам.

> ⚠️ **Репозиторий должен быть Private.** Здесь будут ФИО и аккаунты детей. Если он публичный, робот остановится и ничего не запишет. Settings → General → Danger Zone → Change visibility → **Private**.

## Что получается

| Файл | Что внутри |
|---|---|
| `README.md` | список групп и сводка (удобно смотреть с телефона) |
| `groups/<группа>/README.md` | таблица группы с галочками ✅❌⏳ |
| `groups/<группа>/ведомость.csv` | то же для Excel: ФИО, GitHub, ник, статус каждого задания, решено, ошибки, даты, ссылка на профиль |
| `groups/_без_группы/` | те, кто не указал группу |
| `all.csv` | все ученики одним файлом |
| `data/submissions.csv` | журнал всех сдач (дата, аккаунт, задание, статус, ссылка) |
| `students.csv` | **список учеников: правишь ты** |

## Как пользоваться

1. Сделай репозиторий Private (см. выше).
2. Вкладка **Actions** → «Обновить ведомость» → **Run workflow**. Дальше робот обновляется сам раз в час.
3. Робот сам дописывает в `students.csv` каждый новый GitHub-аккаунт. Открой файл (карандаш), впиши **ФИО** напротив аккаунта и, если нужно, поправь **группу**. Твоя запись главнее того, что ученик написал в форме.
4. Через час (или по кнопке Run workflow) ФИО появятся в ведомостях.

Ученики ФИО не пишут: форма на сайте публичная, и ФИО детей оказалось бы в открытом доступе. Они указывают только ник и номер группы, а GitHub-аккаунт робот берёт сам.

Совет: кабинет учителя на сайте курса (вкладка «Ученики») может выгрузить готовый `students.csv`, если ты уже вписывал ФИО там.

## Как устроено

- `bot/sync.py`: Python без сторонних библиотек. Читает Issues, пишет файлы.
- `.github/workflows/sync.yml`: запуск каждый час и по кнопке; перед сбором запускает тесты (`bot/test_sync.py`).
- Защита: отказ работать в публичном репозитории; название папки группы очищается (нельзя записать файл вне `groups/`); ячейки с `=` `+` `-` `@` получают апостроф (защита от формул Excel); код учеников не сохраняется.
